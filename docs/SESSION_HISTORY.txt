================================================================================
Mobile-first law practice management SaaS with:

### UUID Conversion (src/lib/firebase/uid.ts)
- Firebase UIDs (e.g., Vp4z6gBWqrbrKZIEcXBbm1c1K3z1) are NOT valid UUIDs
- Supabase profiles.id requires UUID format
- Solution: firebaseUidToUuid(uid) generates deterministic UUID via double hash

## DATABASE STRUCTURE
================================================================================

### Key Tables
- profiles: id (UUID), firm_id, role, full_name, email, phone, payment_type, monthly_salary, percentage_rate, pf_enabled, esi_enabled, tds_rate, upi_id, allotment_status
- cases: id, firm_id, created_by, assigned_to, status, case_number, title, acts, sections, clauses
- clients: id, firm_id, created_by, full_name, phone
- invoices: id, firm_id, amount, tax_amount, status (sent/overdue/paid)
- payments: id, firm_id, received_by, amount, payment_date
- hearings: id, case_id, firm_id, hearing_date, court_name, judge_name
- salary_payments: id, employee_id, firm_id, base_salary, pf_deduction, esi_deduction, tds_deduction, net_payable
- team_members: id, firm_id, user_id, role
- consultation_slots: id, lawyer_id, day_of_week, start_time, end_time, fee
- case_alerts: id, user_id, case_id, is_active, channels
- collection_logs: id, invoice_id, firm_id, user_id, action
- contact_submissions: id, name, email, phone, subject, message
