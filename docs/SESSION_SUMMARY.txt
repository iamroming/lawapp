ISSUE 1: Super Admin Page Error
-------------------------------
Problem: All 10 super-admin pages showed "Missing NEXT_PUBLIC_SUPABASE_URL or SUPABASE_SERVICE_ROLE_KEY" error.

Root Cause: All super-admin pages were "use client" components but directly called createServiceRoleClient() at the top level. SUPABASE_SERVICE_ROLE_KEY (without NEXT_PUBLIC_ prefix) is only available server-side, so it was undefined in the browser.

Fix: Replaced direct createServiceRoleClient() calls with server actions from @/app/actions/super-admin which run server-side where the env vars are available.

Files Modified:
- src/app/actions/super-admin.ts - Added server actions for mutations (toggle active, change role, update status, delete, etc.)
- src/app/(super-admin)/super-admin/page.tsx
- src/app/(super-admin)/super-admin/users/page.tsx
- src/app/(super-admin)/super-admin/users/[id]/page.tsx
- src/app/(super-admin)/super-admin/cases/page.tsx
- src/app/(super-admin)/super-admin/clients/page.tsx
- src/app/(super-admin)/super-admin/subscriptions/page.tsx
- src/app/(super-admin)/super-admin/revenue/page.tsx
- src/app/(super-admin)/super-admin/coupons/page.tsx
- src/app/(super-admin)/super-admin/activity/page.tsx
- src/app/(super-admin)/super-admin/documents/page.tsx
- src/app/(super-admin)/super-admin/settings/page.tsx

Commit: fix: move createServiceRoleClient from client components to server actions

ISSUE 2: Subscription Plans Management Module
---------------------------------------------
Request: Create a module for super admin to create/edit subscription plans (pricing plans).

What Was Built:
1. Server Actions (src/app/actions/super-admin.ts):
   - getSuperAdminPlans() - Fetch all plans
   - createSuperAdminPlan() - Create a new plan
   - updateSuperAdminPlan() - Update an existing plan
   - deleteSuperAdminPlan() - Delete a plan (with active subscription protection)
   - toggleSuperAdminPlanActive() - Toggle plan active/inactive

2. Plans Page (src/app/(super-admin)/super-admin/plans/page.tsx):
   - Stats cards: Total Plans, Active Plans, Monthly Plans, Yearly Plans
   - Plan cards showing: name, slug, price, billing period, description, features, limits (cases/users/storage)
   - Create/Edit modal form with all plan fields
   - Toggle active/inactive status
   - Delete with protection (cannot delete plans with active subscriptions)
   - Empty state when no plans exist

3. Sidebar (src/components/super-admin-sidebar.tsx):
   - Added "Plans" nav link with Package icon between Subscriptions and Coupons

Plan Schema (subscription_plans table):
   - id, name, slug, description, price, billing_period (monthly/yearly/one_time)
   - features (string[]), max_cases, max_users, max_storage_mb
   - is_active, created_at, updated_at
