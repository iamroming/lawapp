========================================
CRON-JOB.ORG SETUP GUIDE
========================================

STEP 1: Sign Up
Go to https://cron-job.org and create free account


STEP 2: Create Cron Job

Click "Create Cron Job" button


STEP 3: Fill Form

URL: paste the URL from below
Method: GET
Schedule: pick from below

IMPORTANT: Headers kahan daalein?
---------------------------------

Form mein neeche scroll karo, "Headers" section dikhega:

┌─────────────────────────────────────────────┐
│                                             │
│ URL: https://www.casefiles.in/api/...       │
│                                             │
│ Method: GET                                 │
│                                             │
│ Schedule: 0 9 * * *                         │
│                                             │
│ ─────────────────────────────────────────   │
│ Headers (scroll down)                       │
│ ─────────────────────────────────────────   │
│                                             │
│ Key:    X-Cron-Secret                       │
│ Value:  casefiles-cron-secret-2026          │
│                                             │
│ [Add Header] button pe click karke add karo │
│                                             │
│ ─────────────────────────────────────────   │
│                                             │
│ [Save]                                      │
└─────────────────────────────────────────────┘


STEP 4: Save and Test

"Test" button se check karo ki kaam kar raha hai
