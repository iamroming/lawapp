STEP 1: ADD MISSING ENVIRONMENT VARIABLES
==========================================

Go to your .env.local file and add these 7 keys:

# WhatsApp (Twilio)
TWILIO_ACCOUNT_SID=your_twilio_account_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_PHONE_NUMBER=+1234567890

# Email (Resend)
RESEND_API_KEY=your_resend_api_key
RESEND_FROM_EMAIL=noreply@casefiles.in

# SMS (MSG91)
MSG91_API_KEY=your_msg91_api_key

# Cron Jobs
CRON_SECRET=your_random_secret_string


Where to get these:
- Twilio: https://console.twilio.com (sign up, get free trial number)
- Resend: https://resend.com (sign up, verify domain)
- MSG91: https://msg91.com (sign up, get API key)
- CRON_SECRET: Just make up a random string like "my-secret-123"


STEP 2: ADD SAME KEYS TO VERCEL
================================

Go to Vercel Dashboard > your project > Settings > Environment Variables

Add the same 7 keys there with the same values.


STEP 3: RUN SQL MIGRATIONS IN SUPABASE
