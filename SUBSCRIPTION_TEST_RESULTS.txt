  │                                                                          │
  │ VERDICT:  Design decision, not a bug. Daily reset is common in SaaS.    │
  │           However, the marketing page says "100 AI queries/month"        │
  │           which is misleading.                                           │
  │                                                                          │
  │ RECOMMENDATION: Either change the code to monthly reset or update        │
  │                 the marketing copy to say "per day".                     │
