======================================================================
REMAINING KNOWN ISSUES
======================================================================

These issues require architectural changes beyond simple bug fixes:

1. No API Routes for Super Admin (Systemic #A)
   All super admin operations are client-side Supabase queries.
   Creating 10+ API routes with proper auth, audit logging, and
   validation is a significant architectural task.

2. N+1 on Users Page (Systemic #B)
   Fixed for analytics but users page still has per-user queries.
   Requires a batch query or RPC approach.

3. No Pagination on Users/Cases/Clients Pages (Systemic #C)
   All load entire tables. Needs cursor-based or offset pagination.

4. In-Memory Rate Limiter (from Round 1)
   Serverless functions get fresh Maps. Requires Redis/Upstash.

5. DB Migrations Needed
   - next_invoice_number RPC function
   - coupon_uses(coupon_id,user_id) unique constraint
   - firm_id columns on collection_logs and time_entries
