CRITICAL BUGS (Security / Data Leak / Crash)
======================================================================

#1 Clients API Cross-Tenant Data Access (IDOR)
  File: src/app/api/clients/[id]/route.ts:14-19,59-66,92-99
  Bug: GET/PUT/DELETE by id without firm_id filter. Owner of Firm A
       can read/update/delete any client from Firm B.
  Impact: Complete cross-tenant data breach on clients.

#2 Super Admin Cross-Firm Queries Blocked by RLS
  File: All super-admin/* pages
  Bug: firm-isolation RLS policies restrict rows to user's firm_id.
       Super admin only sees their own firm's data, not platform-wide.
  Impact: Super admin dashboard is non-functional.

#3 Super Admin Can Escalate Privileges
  File: src/app/(super-admin)/super-admin/users/[id]/page.tsx:140
  Bug: Role Select includes "super_admin" option. Any super admin can
       promote any user to super admin.
  Impact: Privilege escalation. Compromised account creates more admins.

#4 Super Admin Can Deactivate Other Super Admins
  File: src/app/(super-admin)/super-admin/users/[id]/page.tsx:62-67
  Bug: No guard against deactivating super admins.
  Impact: Super admin can lock out all other super admins.

#5 Case Delete Cascading Missing firm_id
  File: src/app/(dashboard)/cases/[id]/page.tsx:239-242
  Bug: Four cascading soft-deletes have no .eq("firm_id", ...) filter.
  Impact: If RLS is misconfigured, any user can delete any firm's data.

#6 Dashboard Ecourts/Alerts Broken firm_id Scoping
  File: src/app/(dashboard)/dashboard/page.tsx:200-203,256
  Bug: Supabase .eq() doesn't support dot notation on joined tables.
       Filters like "case.firm_id" are silently ignored.
  Impact: Ecourts count and alerts show data from ALL firms.

#7 Billing Pages Module-Level Supabase Client
  Files: billing/new/page.tsx:12, billing/outstanding/page.tsx:19
  Bug: createClient() at module scope in "use client" components.
       Auth state goes stale across requests.
  Impact: Stale auth can show wrong data or cause auth failures.

#8 Billing Clients/Cases No firm_id Scoping
  Files: billing/new/page.tsx:50-53, billing/outstanding/page.tsx:63-66
  Bug: Clients and cases fetched without firm_id filter.
  Impact: Dropdowns show ALL clients/cases across ALL firms.

#9 Cases API No Role Check on PUT/DELETE
    File: src/app/api/cases/[id]/route.ts:59,83
    Bug: Any user can update or delete any case in the firm.

#10 Cases API PUT No client_id Firm Validation
    File: src/app/api/cases/[id]/route.ts:43-51
    Bug: New client_id not validated for firm ownership on update.
    Impact: Case can be reassigned to another firm's client.

#11 Invoices API case_id Not Validated for Firm
    File: src/app/api/invoices/route.ts:87
    Bug: case_id inserted without verifying firm ownership.
    Impact: Cross-tenant invoice-to-case linkage.

#12 Invoices API amount Not Validated as Number
    File: src/app/api/invoices/route.ts:29
    Bug: String amounts pass validation ("100" <= 0 is false).
    Impact: Financial calculations corrupted.

#13 Expenses API case_id/client_id No Firm Validation
    File: src/app/api/expenses/route.ts:89-103,140-137
    Bug: case_id and client_id inserted without firm ownership check.
    Impact: Cross-tenant foreign key injection.

#14 Subscriptions API GET Queries Wrong Column
    File: src/app/api/subscriptions/route.ts:64
    Bug: eq("user_id", profile.firm_id) filters by firm_id value
         instead of firm owner's user_id.
    Impact: Returns wrong user's subscription data.

#15 Payments verify planSlug Not Validated
    File: src/app/api/payments/verify/route.ts:63
    Bug: Any string accepted as planSlug. No validation against PLANS.
    Impact: Attacker can claim enterprise plan without paying.

#16 Payments verify billingCycle Not Validated
    File: src/app/api/payments/verify/route.ts:69
    Bug: Any string accepted. "annual" gives 12 months for monthly price.
    Impact: Billing cycle manipulation possible.

#17 AI Research Topic Filter Broken
    File: src/app/api/ai/research/route.ts:43
    Bug: act/section params destructured but never passed to function.
    Impact: Topic dropdown has zero effect on results.

#18 AI Drafting Imports Server Code to Client
    File: src/app/(dashboard)/ai/drafting/page.tsx:22-23
    Bug: Imports from @/lib/ai/drafting which imports AI_API_KEY.
    Impact: Server secret bundled into client JS.

#19 AI Summarize Uses Wrong Endpoint
    File: src/app/(dashboard)/ai/summarize/page.tsx:39
    Bug: Calls /api/ai/analyze instead of /api/ai/summarize.
    Impact: Wrong AI prompt, usage tracked under wrong category.

#20 Case Create No Null Guard on User
    File: src/app/(dashboard)/cases/new/page.tsx:172-174
    Bug: If user is null, firm_id is undefined in insert.
    Impact: Case created with no firm association.

#21 Client Create No Null Guard on User
    File: src/app/(dashboard)/clients/new/page.tsx:86-88
    Bug: Same pattern — user null = undefined firm_id.
    Impact: Client created with no firm association.

#22 Case Delete No Error Handling on Cascading
    File: src/app/(dashboard)/cases/[id]/page.tsx:239-242
    Bug: Four cascading updates with no error capture.
    Impact: Partial deletion leaves orphaned records silently.

#23 Subscription Free Plan Dead Code
    File: src/app/api/subscriptions/route.ts:113
    Bug: planSlug === "free" unreachable (not in PLANS).
    Impact: Free plan activation path non-functional.

#24 Expenses Hard DELETE Instead of Soft Delete
    File: src/app/api/expenses/route.ts:169
    Bug: Uses .delete() while all other routes use deleted_at.
    Impact: Permanent data loss, inconsistent with rest of app.
