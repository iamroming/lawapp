4. EMPLOYEE CREATION METHODS & BUGS
======================================================================

METHOD 1: EMAIL INVITE (Settings > Team > Add by Email)
- Only works for EXISTING users (must already have account)
- Owner/partner enters email + role → API updates profiles
- User is immediately added (no invite acceptance flow)

METHOD 2: INVITE CODE (Admin > Add Employee or Settings > Team)
- Owner generates code with role, salary, payment details
- Code stored in team_invites (expires 7 days)
- Code displayed/shared with employee

METHOD 3: CODE REDEMPTION (Employee signup flow)
- New user → /signup → "I'm a Team Member" → enters code
- Creates auth account → onboarding → redeems code
- API updates profiles (role + firm_id)

METHOD 4: OWNER SIGNUP (creates a new firm)
- User signs up as "Firm Owner" → role='owner', firm_id=self
