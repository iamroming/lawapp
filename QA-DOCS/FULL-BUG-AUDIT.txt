CRITICAL BUGS
================================================================================

C1. SERVICE ROLE KEY EXPOSED IN CLIENT BUNDLE
  Files: All super-admin and admin pages using createServiceRoleClient()
  Problem: createServiceRoleClient() embeds SUPABASE_SERVICE_ROLE_KEY into
  client-side JavaScript. Anyone can extract it from DevTools → Sources.
  Impact: Full database admin access bypasses ALL RLS policies.
  Fix: Move ALL service-role queries to API routes or Server Actions.

C2. ADMIN PAGES WILL NEVER LOAD (getUser with Service Role Client)
  Files: admin/users/page.tsx:37, admin/users/[id]/page.tsx:74
  Problem: createServiceRoleClient().auth.getUser() returns null because
  the service role client has no authenticated session.
  Impact: Admin users page shows "Loading users..." forever. Never loads.
  Fix: Use createClient() for user auth, service role only for data queries.

C3. CROSS-TENANT DATA LEAK — Documents Download
  File: documents/[id]/download/route.ts:32
  Problem: Document query has no firm_id filter. Any user can download
  any document by guessing the UUID.
  Impact: Firm A downloads Firm B's confidential documents.
  Fix: Add .eq("firm_id", firmId) to the query.

C4. CROSS-TENANT DATA LEAK — Quotations
  File: quotations/[id]/route.ts:10-60
  Problem: GET, PUT, DELETE all lack firm_id filtering.
  Impact: Any user can read/modify/delete any quotation.
  Fix: Add firm_id check to all operations.

C5. STORAGE LIMIT CHECK IS DEAD CODE
  File: documents/route.ts:96
  Problem: allowedFields.file_size = 0 forces size to 0, so the entire
  storage limit check (lines 103-163) never executes.
  Impact: Users upload unlimited files regardless of plan.
  Fix: Remove the forced file_size = 0 line.

C6. DEADLINE REMINDERS NEVER FIRE VIA CRON
  File: deadlines/check/route.ts:38
  Problem: When called via cron, userId is null. Query .eq("created_by",
  null) matches nothing in PostgreSQL (NULL != NULL).
  Impact: Automated deadline reminders are completely broken.
  Fix: Skip created_by filter for cron calls.

C7. CAUSE LIST SYNC NEVER WORKS VIA CRON
  File: cause-list/sync/route.ts:29
  Problem: Same null userId bug as C6.
  Impact: Cause list entries never sync automatically.
  Fix: Same as C6.

C8. DUPLICATE checkSuperAdminAccess FUNCTION
  Files: actions/super-admin.ts:6 AND actions/check-super-admin.ts:6
  Problem: Both files export identical checkSuperAdminAccess functions.
  Impact: Import ambiguity, dead code, maintenance hazard.
  Fix: Remove from super-admin.ts.

C9. isRazorpayConfigured CRASHES IF ENV VAR MISSING
  File: lib/env.ts:45-51
  Problem: .includes() called on undefined RAZORPAY_KEY_ID throws TypeError.
  Impact: Server crash if Razorpay env var not set.
  Fix: Guard: if (!process.env.RAZORPAY_KEY_ID) return false;

C10. HEARINGS POST DOESN'T SET firm_id
  File: api/hearings/route.ts:63-65
  Problem: Hearing insert doesn't include firm_id. If column has no default,
  hearings are created without firm scoping.
  Impact: Hearings invisible in firm-wide views, daily digest shows none.
  Fix: Add firm_id: profile?.firm_id || user.id to the insert.
