CRITICAL BUGS (Fix Immediately)
======================================================================

#1 Payment Verification Bypass
  File: src/app/api/payments/verify/route.ts
  Bug: If Razorpay payments.fetch() fails, the catch block does NOT
       return. Execution continues and activates the subscription
       without valid payment.
  Impact: Users get free subscriptions by triggering payment errors.
  Fix: Add return after the catch block.

#2 Payment Signature Timing Attack
  File: src/app/api/payments/verify/route.ts
  Bug: Signature comparison uses !== instead of crypto.timingSafeEqual.
  Impact: Attacker can guess signature character by character.
  Fix: Use crypto.timingSafeEqual(Buffer.from(a), Buffer.from(b)).

#3 Coupon Race Condition
  File: src/app/api/coupons/apply/route.ts
  Bug: current_uses increment is not atomic. Two concurrent requests
       can both pass the lt check and both increment.
  Impact: Extra coupon uses beyond max_uses limit.
  Fix: Use UPDATE ... WHERE current_uses < max_uses RETURNING id.

#4 Invoice Number Race Condition
  File: src/app/api/invoices/route.ts
  Bug: Invoice number generation reads last number, computes next,
       then inserts — not atomic. Concurrent requests = duplicates.
  Impact: Duplicate invoice numbers.
  Fix: Use database sequence or atomic RPC function.

#5 Free Coupon Subscription Bypass
  File: src/app/api/payments/create-order/route.ts
  Bug: Free coupon activation doesn't check for existing active
       subscription. User can apply multiple free coupons.
  Impact: Unlimited free subscriptions.
  Fix: Deactivate existing subscription before creating new one.

#6 Share Route IDOR
  File: src/app/api/share/route.ts
  Bug: Share route fetches records by ID without firm_id check.
       Any user can share any other firm's data by guessing UUIDs.
  Impact: Cross-firm data leak.
  Fix: Add .eq("firm_id", firmId) to all queries.

#7 Admin Setup Endpoint Still Accessible
  File: src/app/api/admin-setup/route.ts
  Bug: Returns 410 Gone but file still exists. Could be re-enabled.
  Impact: Potential super admin bootstrap exploitation.
  Fix: Delete the file entirely.
