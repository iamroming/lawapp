CRITICAL FIXES (8)

#1 Clients API IDOR (Insecure Direct Object Reference)
  File: src/app/api/clients/[id]/route.ts
  Bug: GET/PUT/DELETE had no firm_id filter. Owner of Firm A could
       read/update/delete any client from Firm B.
  Fix: Added .eq("firm_id", firmId) to all three endpoints. Removed
       the isOwner bypass that skipped firm filtering.

#2 Super Admin Cross-Firm Queries Blocked by RLS
  Files: src/lib/supabase/client.ts, src/contexts/super-admin-provider.tsx,
         src/app/(super-admin)/layout.tsx, all 11 super admin pages
  Bug: firm-isolation RLS policies restricted super admin to own firm.
  Fix: Created createServiceRoleClient() helper using
       SUPABASE_SERVICE_ROLE_KEY. Created SuperAdminClientProvider
       context. All super admin pages now use service-role client.

#3 Super Admin Privilege Escalation
  File: src/app/(super-admin)/super-admin/users/[id]/page.tsx
  Bug: Role Select included "super_admin" option. Any super admin
       could promote any user to super admin.
  Fix: Removed "super_admin" from role dropdown. Added guard in
       updateRole() that rejects super_admin value.

#4 Super Admin Deactivation Guard
  Files: src/app/(super-admin)/super-admin/users/[id]/page.tsx,
         src/app/(super-admin)/super-admin/users/page.tsx
  Bug: No guard against deactivating super admins.
  Fix: Added super_admins table check in toggleActive(). Deactivate
       button disabled for super_admin targets.

#5 Case Delete Missing firm_id
  File: src/app/(dashboard)/cases/[id]/page.tsx
  Bug: Four cascading soft-deletes had no .eq("firm_id", ...) filter.
  Fix: Added firmId state from profile. Added .eq("firm_id", firmId)
       to all four cascading update queries.

#6 Dashboard Ecourts/Alerts Broken firm_id Scoping
  File: src/app/(dashboard)/dashboard/page.tsx
  Bug: Supabase .eq() doesn't support dot notation on joined tables.
       Filters like "case.firm_id" were silently ignored.
  Fix: Replaced broken dot-notation queries with .in("case_id", caseIds)
       using already-fetched firm-scoped case IDs.

#7 Billing Pages Stale Auth
  File: src/app/(dashboard)/billing/new/page.tsx
  Bug: createClient() at module scope caused stale auth state.
  Fix: Moved createClient() inside the component.

#8 Billing Pages No firm_id Scoping
  Files: billing/new/page.tsx, billing/outstanding/page.tsx
  Bug: Clients/cases fetched without firm_id filter.
  Fix: Added profile fetch and .eq("firm_id", profile.firm_id) to
       all client/case queries.
