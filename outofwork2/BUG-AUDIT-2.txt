BUG #1 — Hardcoded admin email in production API route
  File: src/app/api/admin-setup/route.ts (line 8)
  Description: The admin-setup route hardcodes a specific email (mubb@ymail.com)
    to grant super_admin access. This is a hardcoded backdoor. Anyone who
    discovers this route can grant themselves super_admin.
  Fix: Remove hardcoded email. Use env var or remove the route entirely.

BUG #2 — CSRF validation uses simple cookie equality, not HMAC
  File: src/middleware.ts (lines 41-48)
  Description: CSRF check compares csrf_cookie === csrf_header as plain text
    equality. The HMAC-signed tokens in csrf.ts are NOT used in middleware.
    An attacker can set any cookie value and pass same value in header.
  Fix: Use the HMAC verification from csrf.ts in middleware validation.

BUG #3 — CSRF fallback secret in source code
  File: src/lib/csrf.ts (line 3)
  Description: CSRF_SECRET falls back to "fallback-csrf-secret" when env var
    is missing. CSRF tokens signed with publicly known secret.
  Fix: Throw error if CSRF_SECRET is not set. Never use fallback.
