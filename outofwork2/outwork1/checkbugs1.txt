1. SECURITY FLAWS (17 Critical)
============================================================

S-1. API Keys Exposed in .env.local
  File: .env.local
  Issue: Real AI API key, Supabase URL/anon key, Cloudinary secret,
         eCourts live key, and DB password are committed to source.
  Fix: Rotate ALL keys immediately. Add .env.local to .gitignore.

S-2. CSRF Token Validates Nothing
  File: src/lib/csrf.ts
  Issue: CSRF_SECRET falls back to NEXT_PUBLIC_SUPABASE_ANON_KEY
         (a public value). Token has no session binding. No API
         route calls validateCsrfToken().
  Fix: Use a proper secret. Bind tokens to sessions.

S-3. Rate Limiting Never Applied
  File: src/lib/rate-limit.ts
  Issue: checkRateLimit() exists but is never imported or called
         in any API route.
  Fix: Apply to all API routes, especially auth endpoints.

S-4. Admin/Super-Admin Auth is Client-Side Only
  Files: src/app/(admin)/layout.tsx, src/app/(super-admin)/layout.tsx
  Issue: Content renders before redirect (flash of unauthorized content).
  Fix: Remove client-side checks since middleware handles it.

S-5. Documents Page Does Hard Delete Bypassing API
  File: src/app/(dashboard)/documents/page.tsx (line 124)
  Issue: handleDelete calls supabase.from("documents").delete()
         directly - a HARD delete. API route does soft delete.
  Fix: Always use the API route for deletions.

S-6. Client Detail Page Does Hard Deletes
  File: src/app/(dashboard)/clients/[id]/page.tsx (lines 66-81)
  Issue: Hard deletes hearings, time_entries, cases, and client
         directly from client code, bypassing all protections.
  Fix: Route through API endpoints.

S-7. Case Detail Page Does Hard Deletes
  File: src/app/(dashboard)/cases/[id]/page.tsx (lines 89-101)
  Issue: Same as S-6 for cases.
  Fix: Route through API endpoints.

S-8. Webhook Endpoint Has No Signature Verification
  File: src/app/api/subscriptions/webhook/route.ts
  Issue: Accepts any POST body without verifying Razorpay webhook
         signature. Attacker can forge subscription events.
  Fix: Verify HMAC signature using RAZORPAY_WEBHOOK_SECRET.

S-9. Signature Comparison Vulnerable to Timing Attacks
  Files: src/app/api/subscriptions/verify/route.ts (line 19),
         src/lib/payments/razorpay.ts (line 76)
  Issue: Uses !== instead of crypto.timingSafeEqual().
  Fix: Use crypto.timingSafeEqual() for all comparisons.

S-10. Conflict Check Not Scoped to User
  File: src/app/api/clients/conflict-check/route.ts
  Issue: Queries clients table without filtering by created_by.

  Fix: Add .eq("created_by", user.id) to all queries.

S-11. Reports Route Missing User Filtering
  File: src/app/api/reports/route.ts (lines 76-88)
  Issue: Revenue report fetches ALL payments/invoices globally.
  Fix: Add .eq("received_by", user.id) filter.

S-12. Dashboard API Hearing Data Not User-Scoped
  File: src/app/api/dashboard/route.ts (lines 27-34)
  Issue: Fetches ALL upcoming hearings globally.
  Fix: Filter through cases table by created_by/assigned_to.

S-13. Audit Logs API Missing User Filtering
  File: src/app/api/audit/route.ts
  Issue: Returns ALL audit logs without user filtering.
  Fix: Add .eq("user_id", user.id).

S-14. Documents API Missing User Scoping
  File: src/app/api/documents/route.ts (lines 12-16)
  Issue: Returns ALL documents across the platform.
  Fix: Add uploaded_by filter.

S-15. Tags API Missing User Scoping

  Issue: Returns ALL tags without filtering.
  Fix: Add created_by filter.

S-16. No RLS Enforcement in Client Code

  Files: src/app/api/cases/[id]/route.ts, src/app/api/clients/[id]/route.ts

  File: src/app/api/documents/route.ts (lines 36-39)

  Fix: Apply documentSchema.safeParse(body).

  Fix: Create and apply a tags schema.

  File: src/app/api/reminders/route.ts (lines 12-30)

  Fix: Use the reminderSchema.

A-5. AI Routes Have No Input Validation
  Files: src/app/api/ai/research/route.ts, src/app/api/ai/analyze/route.ts
  Issue: Accept arbitrary body without validation or length limits.
  Fix: Add input validation and length limits.

A-6. Cases POST - No Ownership Check on client_id
  File: src/app/api/cases/route.ts (line 52)
