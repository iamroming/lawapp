# Employee Salary Module - Plan

## Overview
Add salary/compensation management for employees with two payment types:
1. **Fixed Salary** - Monthly salary regardless of cases
2. **Case Percentage** - Get a % of fees collected from assigned cases

---

## How Other Legal Apps Handle This

### Clio
- Tracks billable hours per attorney
- Generates revenue reports by attorney
- No built-in salary module (uses QuickBooks integration)

### MyCase
- Financial reporting by attorney
- Tracks billable time and collections
- Salary management via external accounting

### PracticePanther
- Time tracking with billing rates
- Compensation tracking in reports
- Links payments to specific cases/attorneys

### LeanLaw
- Compensation tracking reports
- Profit-sharing calculations
- Links attorney work to revenue

### Indian Legal Apps (LegalForce, CaseFox)
- Simple salary modules
- Some have percentage-based payment for advocates

---

## Recommended Model for Causly

### Payment Types

#### 1. Fixed Salary (Monthly)
- Set monthly salary amount
- Attendance tracking (optional)
- Deductions (PF, ESI, TDS)
- Payment date (1st/15th of month)
- Bonus provisions

#### 2. Case Percentage
- Set percentage (e.g., 30% of collected fees)
- Only applies to cases where employee is assigned
- Calculated on collected amount (not billed)
- Can set different % per case type
- Monthly settlement or per-case settlement

#### 3. Hybrid (Optional - Phase 2)
- Base salary + smaller percentage
- Best for associates who bring clients

## Database Schema

### employees (existing - add columns)
```sql
ALTER TABLE employees ADD COLUMN payment_type TEXT DEFAULT 'salary';
-- Values: 'salary', 'percentage', 'hybrid'

ALTER TABLE employees ADD COLUMN monthly_salary NUMERIC DEFAULT 0;
ALTER TABLE employees ADD COLUMN percentage_rate NUMERIC DEFAULT 0;
-- e.g., 30 means 30%

ALTER TABLE employees ADD COLUMN payment_day INTEGER DEFAULT 1;
-- Day of month for salary payment

ALTER TABLE employees ADD COLUMN pf_enabled BOOLEAN DEFAULT false;
ALTER TABLE employees ADD COLUMN esi_enabled BOOLEAN DEFAULT false;
ALTER TABLE employees ADD COLUMN tds_rate NUMERIC DEFAULT 0;
-- e.g., 10 means 10% TDS
```

### salary_payments (new table)
```sql
CREATE TABLE salary_payments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  employee_id UUID REFERENCES employees(id),
  payment_type TEXT NOT NULL,
  -- 'salary', 'percentage', 'bonus', 'deduction'
  
  period_start DATE,
  period_end DATE,
  
  base_salary NUMERIC DEFAULT 0,
  percentage_earned NUMERIC DEFAULT 0,
  total_earnings NUMERIC DEFAULT 0,
  
  pf_deduction NUMERIC DEFAULT 0,
  esi_deduction NUMERIC DEFAULT 0,
  tds_deduction NUMERIC DEFAULT 0,
  other_deductions NUMERIC DEFAULT 0,
  total_deductions NUMERIC DEFAULT 0,
  
  net_payable NUMERIC DEFAULT 0,
  status TEXT DEFAULT 'pending',
  -- 'pending', 'paid', 'cancelled'
  
  paid_at TIMESTAMPTZ,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### case_earnings (new table)
```sql
CREATE TABLE case_earnings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  case_id UUID REFERENCES cases(id),
  employee_id UUID REFERENCES employees(id),
  invoice_id UUID REFERENCES invoices(id),
  
  invoice_amount NUMERIC DEFAULT 0,
  collected_amount NUMERIC DEFAULT 0,
  percentage_rate NUMERIC DEFAULT 0,
  earned_amount NUMERIC DEFAULT 0,
  
  settled BOOLEAN DEFAULT false,
  settled_in UUID REFERENCES salary_payments(id),
  
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## Calculation Logic

### Percentage Payment
```
For each case assigned to employee:
  earnings = collected_amount * (percentage_rate / 100)
  
Total monthly = sum(earnings for all cases in month)
Deductions = PF + ESI + TDS
Net = Total - Deductions
```

### Salary Payment
```
Base = monthly_salary
Deductions = PF (12%) + ESI (0.75%) + TDS
Net = Base - Deductions
```
