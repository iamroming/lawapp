--- Admin API Routes (require super_admin) ---

POST /api/admin/subscription-override
  - Change any user's plan, status, custom_price, discount_percent
  - Sets override_reason for audit trail

POST /api/admin/subscription-toggle
  - Enable/disable subscriptions for bulk users
  - Sets disabled_at, disabled_reason

POST /api/admin/subscription-discount
  - Apply percentage discounts to selected users
  - 0-100% range

GET/POST /api/admin/coupons
  - List all coupons (GET)
  - Create new coupon (POST)
  - Auto-generates code if not provided

PUT/DELETE /api/admin/coupons/[id]
  - Update coupon details
  - Delete coupon

GET /api/admin/coupons/[id]/uses
  - View coupon usage history

--- User-Facing API Routes ---

POST /api/coupons/validate
  - Validates coupon code without applying
  - Checks active, valid dates, max uses
  - Returns discount info

POST /api/coupons/apply
  - Applies coupon to user's subscription
  - Creates/updates user_subscriptions record
  - Records coupon usage
  - For "free" type: gives 10-year Enterprise access

--- New Page ---

/super-admin/coupons
  - Full coupon management dashboard
  - Stats: total coupons, active, total uses, friend bypass count
  - Create coupon modal with code generator
  - Toggle active/inactive per coupon
  - View usage history per coupon
  - Delete coupons
