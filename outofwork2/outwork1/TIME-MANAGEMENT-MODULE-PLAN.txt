                    TIME MANAGEMENT MODULE — PLAN
                          Causly (LawApp)
================================================================================

1. OVERVIEW
--------------------------------------------------------------------------------
A dedicated Time Management module that enables lawyers and law firms to track
billable hours, manage deadlines, log time entries against cases/clients, and
generate time-based reports. This is a core module for any legal practice
management system as billable hour tracking is the primary revenue driver.

--------------------------------------------------------------------------------
2. FEATURES
--------------------------------------------------------------------------------

2.1 TIMER (Stopwatch)
  - One-click start/stop timer for real-time tracking
  - Live elapsed time display (HH:MM:SS)
  - Auto-save timer state (survives page refresh via localStorage)
  - Attach timer to a case, client, and activity type while running
  - Manual entry option if user forgets to start timer

2.2 MANUAL TIME ENTRY
  - Date picker (default: today)
  - Start time / End time fields (auto-calculates duration)
  - OR direct duration input (hours + minutes)
  - Case selector (optional but encouraged)
  - Client selector (optional)
  - Activity type dropdown:
      - Court Appearance
      - Client Meeting
      - Document Drafting
      - Research
      - Case Review
      - Travel
      - Phone Call
      - Email/Correspondence
      - Negotiation/Mediation
      - Other
  - Description / notes field (what was done)
  - Billable toggle (Yes/No) — some time may be non-billable
  - Hourly rate override (optional, defaults from case or firm rate)
  - Save as draft or submit

2.3 TIME SHEET (Weekly/Monthly View)
  - Calendar grid: rows = days, columns = cases or activity types
  - Color-coded entries (billable vs non-billable)
  - Inline editing (click cell to add/edit entry)
  - Daily/weekly/monthly totals auto-calculated
  - Export to PDF or CSV

2.4 DEADLINES & REMINDERS
  - Statute of Limitations tracker per case
  - Filing deadline tracker
  - Court date reminders (integrate with existing Calendar module)
  - Custom reminders with email/notification alerts
  - Color-coded urgency (overdue, due today, due this week, upcoming)

2.5 BILLING INTEGRATION
  - Time entries feed directly into Invoice generation
  - Hourly rate × hours = line item on invoice
  - Batch-select time entries to add to an invoice
  - Mark entries as "billed" to prevent double-billing
  - Outstanding (unbilled) time summary

2.6 REPORTS & ANALYTICS
  - Time by case (which cases consume most time)
  - Time by client
  - Time by activity type
  - Time by team member (utilization rates)
  - Billable vs non-billable breakdown
  - Revenue per hour (effective rate)
  - Daily/weekly/monthly trends
  - Export reports as PDF or CSV

2.7 TEAM / FIRM LEVEL
  - Owner/partner can view all team members' time entries
  - Approval workflow (optional): entries require partner approval before billing
  - Firm-wide hourly rate settings per role
  - Override rates at case or individual level

--------------------------------------------------------------------------------
3. DATABASE SCHEMA (New Tables)
--------------------------------------------------------------------------------

3.1 time_entries
  - id UUID PRIMARY KEY
  - user_id UUID REFERENCES profiles(id)       -- who logged the time
  - case_id UUID REFERENCES cases(id)           -- which case (optional)
  - client_id UUID REFERENCES clients(id)       -- which client (optional)
  - activity_type TEXT                          -- enum of activity types
  - description TEXT                            -- what was done
  - start_time TIMESTAMPTZ                      -- for timer-based entries
  - end_time TIMESTAMPTZ
  - duration_minutes INTEGER                    -- computed or manual
  - is_billable BOOLEAN DEFAULT true
  - hourly_rate NUMERIC(10,2)                   -- rate at time of entry
  - status TEXT DEFAULT 'submitted'             -- draft/submitted/approved/billed
  - invoice_id UUID REFERENCES invoices(id)     -- linked to invoice if billed
  - created_at TIMESTAMPTZ DEFAULT now()
  - updated_at TIMESTAMPTZ DEFAULT now()

3.2 deadlines
  - id UUID PRIMARY KEY
  - case_id UUID REFERENCES cases(id)
  - title TEXT NOT NULL
  - description TEXT
  - due_date TIMESTAMPTZ NOT NULL
  - deadline_type TEXT                          -- statute_of_limitations/filing/court_date/custom
  - reminder_days INTEGER DEFAULT 7             -- days before to remind
  - is_completed BOOLEAN DEFAULT false
  - completed_at TIMESTAMPTZ
  - created_by UUID REFERENCES profiles(id)
  - created_at TIMESTAMPTZ DEFAULT now()

3.3 firm_settings (additions)
  - default_hourly_rate NUMERIC(10,2)
  - currency TEXT DEFAULT 'INR'
  - time_entry_approval_required BOOLEAN DEFAULT false
