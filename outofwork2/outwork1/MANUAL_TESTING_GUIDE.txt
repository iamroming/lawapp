# LawApp - Manual Testing Guide
## Step-by-Step Testing Instructions

---

## PREREQUISITES

Before testing, ensure you have:
1. ✅ Supabase project created
2. ✅ `.env.local` configured with credentials
3. ✅ `complete-schema.sql` run in Supabase SQL Editor
4. ✅ `lawapp-files` storage bucket created in Supabase
5. ✅ Node.js 18+ installed
6. ✅ Running `npm run dev`
